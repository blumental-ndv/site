# Админ-панель сайта

Первая итерация интерфейса управления контентом для GitHub Pages.

## Разделы контента
- отзывы;
- ЖК и объекты;
- кейсы;
- статьи;
- страницы и SEO.

Ольга — отдельный пользователь админ-панели с ролью редактора, а не карточка специалиста сайта.

## Подключение
1. Создать проект Supabase.
2. Выполнить `supabase/schema.sql` в SQL Editor.
3. В Authentication → URL Configuration добавить URL админки в Redirect URLs.
4. В `admin/admin.js` заполнить `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Это публичные клиентские параметры. Никогда не добавлять service-role key в репозиторий.
5. Создать первого пользователя через Supabase Auth, затем назначить ему роль admin SQL-командой из конца `schema.sql`.
6. Другие пользователи не добавляются. Доступ к данным есть только у пользователя с ролью admin.

## Связи
Предусмотрены связи между отзывами, объектами, кейсами и страницами сайта. Отдельная сущность «специалисты» не используется.

## Важно
Это пока отдельный редактор контентной базы. Публичные страницы сайта ещё не переведены на чтение из Supabase: до завершения следующего этапа сайт продолжит показывать прежний HTML-контент. Сначала подключим чтение опубликованных материалов и проверим отображение, затем постепенно уберём дублирование отзывов и кейсов.
