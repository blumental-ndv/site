# Админка отзывов

Отзывы хранятся в reviews.json. Вход через fine-grained PAT: только blumental-ndv/site, Contents: Read and write, Metadata: Read. Токен вводится в админке и хранится только в памяти вкладки. Не отправляйте токен в чат и не сохраняйте в репозитории. Сохранение создаёт коммит в main, запускающий Pages workflow. Все отзывы публичные; черновики и архив не поддерживаются. При конфликте SHA войдите заново. Supabase оставлен как резервный источник, но синхронизация отключена.
